# مختبر نافس 360 | العرض التجريبي

رحلة تجريبية في علوم المرحلة الابتدائية تشمل القياس القبلي والتدريب بالتغذية الراجعة ومحاكاة القياس البعدي. الأسئلة والنتائج توضيحية. يعمل العرض داخل المتصفح دون تسجيل دخول أو تخزين الدرجات أو إرسالها. يُحفظ تقدم فتح المراحل في المتصفح الحالي. يفتح التدريب بعد القبلي، وتتوالى ثلاث دفعات من 10 أسئلة، ثم تفتح محاكاة البعدي.
