# مختبر نافس 360 | نسخة تجريبية مترابطة

- **الإدارة**: سجل يبدأ فارغًا. أضيفي مدرسة لتحصلي على رمزها، واختاري «رمز المعلمة» لعرض رمز المعلمة التجريبي.
- **المعلمة**: ادخلي بالرمزين. أضيفي طالبة واحدة أو الصقي كشفًا فيه اسم واحد في كل سطر. راجعي معاينة الأسماء قبل الحفظ الجماعي. يمكن تعديل الأسماء أو أرشفة الطالبات.
- **الطالبة**: افتحي بوابة الطالبة، وأدخلي رمز المدرسة واختاري الاسم. احفظي القبلي، ثم أكملي ثلاث دفعات تدريب متتالية. يُفتح البعدي بعد إكمالها.
- **التقارير**: تعرض لوحة المعلمة الدرجات ومؤشرات الإكمال والتغير. يمكن معاينة التقرير الفردي والجماعي وطباعتهما أو تصدير السجل بصيغة CSV.

استخدمي بيانات وهمية. المدرسة والأسماء والدرجات محفوظة في المتصفح نفسه، والرموز أدوات للمعاينة المحلية. توجد رحلة عرض سريعة منفصلة عن سجلات المدارس. بنك العرض علوم، ويستخدم البعدي أسئلة القبلي بترتيب مختلف. التشغيل الفعلي متعدد المستخدمين مرتبط ببيئة Microsoft المعتمدة.

شغّلي محليًا من جذر المشروع `python3 -m http.server 8000`، وافتحي `http://localhost:8000`. اختبارات المشروع `node --test tests/*.test.cjs`.
